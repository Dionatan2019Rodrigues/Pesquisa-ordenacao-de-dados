# Pesquisa e Ordenação de dados

### Sobre
<p style="text-align: justify;">Diciplina do curso de Ciência da Computação que tem por objetivo apresentar algorítimos de ordenação de dados além do que também métodos de pesquisa em base de dados. Abaixo estão listados todos algorítmos desenvolvidos em linguagem C na disciplina :</p> 

### Algorítimos
- Bubble Sort
- Inserção Direta
- Seleção Direta
- Shell Sort
- Quick Sort
- Heap Sort

<p>
    Você encontra o código de cada um deles neste repositório através do caminho <strong>exercicios/metodos_ordenacao.c</strong>
</p>
